# AutoDoc 1.8.0 — Upstream 1.3.4 plus the fork features

This fork release merges upstream AutoDoc 1.3.4 and keeps every fork feature on
top: Mistral API mode for notes and Ask AI, protocol-type meeting notes, the
launch-at-login toggle, in-app updates from this fork's releases, and the
Settings diagnostic report.

Upstream 1.3.4 highlights:

- A faster, more accurate Ask AI beta that searches meeting notes and
  transcripts, with source links that open the recording at the matching moment.
- **Ask about this meeting** from any recording, follow-up questions that stay
  on the same meeting and reply in the language of the question, and a
  background search index with progress.
- Recording safety and privacy fixes, verified and resumable model downloads,
  and crash reports that exclude window and meeting titles.

See the [full changelog](https://github.com/gschmalzhaf-cell/AutoDoc/blob/main/CHANGELOG.md)
for details.
