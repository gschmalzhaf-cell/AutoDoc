# Gideon's Notizen 1.9.0 — Rebrand & Cozy Blue Style

**Gideon's Notizen** is an independent fork of [DuetDisplay/AutoDoc](https://github.com/DuetDisplay/AutoDoc).

## What's new in 1.9.0

- **New Identity ("Gideon's Notizen")**: Rebranded app name, sidebar header, onboarding welcome screen, video watermark, system tray, and Windows/macOS installer metadata.
- **Cozy & Playful Blue Theme**: Redesigned light and dark color palettes around a warm, cozy blue primary color with coral and periwinkle accents, subtle ambient glow, springy micro-interactions, and a new blue app icon.
- **Updated Project Page**: `README.md` now highlights the fork relationship to `DuetDisplay/AutoDoc` and compares all fork features (Mistral API mode, selectable protocol types, launch-at-login toggle, diagnostic report, and fork update feed).

See the [full changelog](https://github.com/gschmalzhaf-cell/AutoDoc/blob/main/CHANGELOG.md) for details.
